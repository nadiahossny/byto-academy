# Byto Academy 🚀

**Byto Academy** is a modern, premium EdTech frontend application built with **Next.js**. It features a fully responsive, sleek dashboard, robust routing, and engaging user interfaces designed to provide a seamless learning experience across all devices.

## 🌟 Key Features

- **Modern Tech Stack**: Built with Next.js (App Router), React, and vanilla CSS for granular styling control.
- **Responsive Dashboard**: A dynamic sidebar layout that perfectly adapts to desktop, tablet, and mobile viewports.
- **Interactive UI**: Features state-managed interactive components, smooth transitions, and premium design aesthetics (glassmorphism, curated color palettes).
- **Core Learning Features**:
  - **Dashboard**: Overview of user progress, active courses, and upcoming tasks.
  - **Resume Learning**: Intelligent routing that allows users to seamlessly jump back into their last active learning session.
  - **Dynamic Routing**: Built-in support for nested course modules and practice environments.
- **Production-Ready Performance**: Fully optimized for fast load times using Next.js static and dynamic rendering capabilities.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React](https://react.dev/)
- **Styling**: Vanilla CSS (Custom design system with CSS Variables)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Syntax Highlighting**: PrismJS
- **Code Editor**: React Simple Code Editor

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## 📦 Production Build

This project is fully optimized and ready for production deployment. To create a production build:

```bash
npm run build
npm run start
```

Open [deployed version](https://byto-academy.vercel.app/)
